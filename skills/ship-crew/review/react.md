# Review pack — React / Next.js

Detect: `package.json` with `react`, `next`, `react-native`, `expo` or `vite` plus a React plugin; `*.tsx` / `*.jsx` files; `app/` or `pages/` directories with `next.config.*`.

Applies on top of core.md and the TypeScript pack; the project's rules win. Find the project's data-fetching library (TanStack Query, SWR, RTK Query, Apollo, server components) and its state store before judging rules about server state.

## Critical
1. **Server-only secret or privileged code reaches the client bundle.** Mechanism: a file with `"use client"`, a pages-router component, or a module imported by one reads a non-public env var, an ORM/admin client, or a server SDK; or a secret is placed in a `NEXT_PUBLIC_` / `VITE_` / `EXPO_PUBLIC_` variable. Public-prefixed values and anything imported by a client module are shipped to every visitor. Spot: imports of db/admin/server modules from client files, props passed from a server component containing full records (tokens, password hashes, other users' fields). Correct: keep the code in server-only modules (`server-only` marker or the project's convention) and pass only the needed fields.
2. **`dangerouslySetInnerHTML` or raw HTML injection with unsanitized content.** Mechanism: user, CMS or API-provided strings rendered as HTML execute scripts (stored XSS). Also `href`/`src` built from user input (`javascript:` URLs) and `innerHTML` set via refs. Spot: any use of these with a non-constant value. Correct: the project's sanitizer (DOMPurify or equivalent) applied at render, or render as text; validate URL schemes.

## High
3. **Hook rules and dependency arrays.** Mechanism: a hook called after an early return, inside a condition or loop crashes or corrupts state between renders; an effect or `useCallback`/`useMemo` that reads a prop, state or function but omits it from deps runs with a stale value forever. Spot: `// eslint-disable react-hooks/exhaustive-deps` added in the diff, objects/functions created in render placed in deps (infinite effect loop). Correct: complete deps, stabilize with `useCallback`/`useMemo` or move values inside the effect.
4. **Effect without cleanup or race handling.** Mechanism: an effect that subscribes, starts a timer, adds a listener or fetches, and does not unsubscribe/clear/abort, leaks on unmount and in strict-mode double-invoke; a fetch in an effect with changing deps lets an older response arrive last and overwrite newer data. Spot: `addEventListener`, `setInterval`, `subscribe`, `fetch` in `useEffect` with no returned cleanup or abort/ignore flag. Correct: return a cleanup; use `AbortController` or an `ignore` flag, or the project's query library.
5. **Stale closure in handlers and timers.** Mechanism: a callback captured in `setInterval`, `setTimeout`, an event listener or a memoized handler sees the state from the render it was created in; `setCount(count + 1)` repeated or after await overwrites updates. Spot: state read inside async code or long-lived callbacks. Correct: functional updates (`setX(prev => ...)`), refs for latest value, correct deps.
6. **Query/cache key missing a parameter.** Mechanism: in TanStack Query, SWR, RTK Query or similar, a fetch function uses an id, filter, page, locale or user, but the cache key does not include it; users see another entity's or user's cached data, or stale results after the parameter changes. Spot: `queryKey: ["items"]` with `fetchItems(filter)` inside. Correct: every variable the fetcher reads is in the key. Also check that keys include the user/tenant when data is per-user.
7. **Mutation that does not refresh what it changed.** Mechanism: a create/update/delete succeeds on the server but the list, detail and counters shown elsewhere stay stale because no invalidation, refetch, `revalidatePath`/`revalidateTag` or optimistic update covers all affected keys; an optimistic update with no rollback on error shows data that was never saved. Spot: mutation hooks and server actions with no invalidation or with a narrower key than the reads. Correct: invalidate every affected key using the project's helper; roll back in `onError`.
8. **Server state copied into a global store or local state.** Mechanism: fetched data duplicated into Redux/Zustand/Context or `useState(initialFromProps)` becomes a second source of truth that does not update when the cache refetches or when props change. Spot: `useEffect(() => setState(data), [data])` and `useState(props.x)` for values that must follow the prop. Correct: read from the query cache or derive during render; use a `key` to reset local state.
9. **Browser-only API at module scope or in render (SSR crash / hydration mismatch).** Mechanism: `window`, `document`, `localStorage`, `navigator` read at import time or during render fails on the server; values like `Date.now()`, `Math.random()`, locale-formatted dates, or `typeof window` branches rendered differ between server and client and cause a hydration mismatch with flicker or discarded markup. Spot: those references outside `useEffect`/event handlers in code that renders on the server. Correct: move into effects, use the framework's client-only mechanism, or a mounted flag.
10. **Next.js caching and revalidation surprises.** Mechanism: a fetch or route handler cached by default serves stale user-specific or frequently changing data; `cookies()`/`headers()` use is expected to make a route dynamic but another cached layer (fetch cache, `unstable_cache`, `revalidate` export) is not keyed per user; a mutation without `revalidatePath`/`revalidateTag` leaves pages stale. Spot: authenticated data fetched in a cacheable context, missing `cache: "no-store"` or dynamic marker where the project's Next version defaults to caching. Check the version's defaults and the project's pattern before reporting.
11. **Server actions and route handlers trust the client.** Mechanism: a server action is a public POST endpoint; one that takes ids or role flags from arguments without re-checking session and ownership is exposed regardless of UI hiding the button. Spot: `"use server"` functions with no auth call. Correct: use the project's auth helper inside the action itself. (Complements core rule 1.)
12. **Middleware and redirect order.** Mechanism: middleware matchers that miss new routes (or `/api`, static-adjacent paths) leave them unprotected; `redirect()` and `notFound()` throw and must not sit inside `try/catch` that swallows them; a redirect placed after a side effect, or a login redirect that loops because the target is itself matched. Spot: changed `matcher`, `redirect` inside `try`, new routes with no matcher coverage. Correct: confirm the matcher covers the route; call redirect outside try or rethrow.
13. **List keys that are unstable.** Mechanism: array index or `Math.random()` as `key` on a list that reorders, inserts or deletes remounts items or attaches input state, focus and animation to the wrong row. Spot: `key={index}` on dynamic, editable or reorderable lists. Correct: a stable id from the data.

## Medium
14. **Expensive or unstable work in render.** Mechanism: a new object/array/function literal passed as a prop or context value each render defeats `memo` and re-renders every consumer; heavy computation or sorting of large lists in render with no memoization. Spot: context `value={{...}}` without `useMemo`, large lists with no virtualization where the project uses it. Correct: memoize only where a measurable list or context fan-out exists.
15. **React Native specifics.** Mechanism: `FlatList` with inline `renderItem` and no `keyExtractor`, listeners from `AppState`/`Keyboard`/`Linking` or navigation events not removed, secrets or tokens stored in plain AsyncStorage instead of the project's secure storage. Spot: these in changed screens. Correct: use the project's secure storage and cleanup patterns.

## Do not report
- Missing `useMemo`/`useCallback`/`React.memo` with no measured or obvious render problem.
- `useEffect` for something a project convention allows, or a dependency array the lint rule (`react-hooks/exhaustive-deps`) already passes.
- `key={index}` on static, never-reordered lists.
- Hydration warnings caused by browser extensions, or `suppressHydrationWarning` on a timestamp element.
- Public-prefixed env vars that hold values meant to be public (analytics site id, public API base URL).
- Class components, prop drilling, file layout, or choice of state library as taste.
